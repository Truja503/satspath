\hypertarget{arkade-wallet}{%
\section{👾 Arkade Wallet}\label{arkade-wallet}}

Arkade Wallet is the entry-point to the Arkade ecosystem---a
self-custodial Bitcoin wallet delivered as a lightweight Progressive Web
App (installable on mobile or desktop in seconds, no app-store
gatekeepers). Built around the open-source ARK protocol, it speaks
natively to any \href{https://github.com/arkade-os/arkd}{arkd} instance,
letting you create, send, and receive Virtual Transaction Outputs
(VTXOs) for instant, off-chain pre-confirmations and batched,
fee-efficient on-chain settlement.

The wallet is available as a Docker image on GitHub Container Registry.

\hypertarget{pull-and-run}{%
\subsubsection{Pull and run}\label{pull-and-run}}

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{docker}\NormalTok{ pull ghcr.io/arkade{-}os/wallet:latest}

Open \url{http://localhost:8080} to view the wallet.

\hypertarget{runtime-configuration}{%
\subsubsection{Runtime configuration}\label{runtime-configuration}}

without rebuilding the image:

\begin{Shaded}
\begin{Highlighting}[]

  \AttributeTok{{-}e}\NormalTok{ VITE\_ARK\_SERVER=https://arkade.computer }\DataTypeTok{\textbackslash{}}
  \AttributeTok{{-}e}\NormalTok{ VITE\_BOLTZ\_URL=https://api.boltz.exchange }\DataTypeTok{\textbackslash{}}
\NormalTok{  ghcr.io/arkade{-}os/wallet:latest}
\end{Highlighting}
\end{Shaded}

See the \protect\hyperlink{environment-variables}{Environment Variables}
table for all supported variables.

\hypertarget{pnpm-run-start}{%
\subsubsection{\texorpdfstring{\texttt{pnpm\ run\ start}}{pnpm run start}}\label{pnpm-run-start}}

Runs the app in the development mode.\\
Open \url{http://localhost:3002} to view it in the browser.

The page will reload if you make edits.\\
You will also see any lint errors in the console.

\hypertarget{pnpm-run-build}{%
\subsubsection{\texorpdfstring{\texttt{pnpm\ run\ build}}{pnpm run build}}\label{pnpm-run-build}}

Builds the app for production to the \texttt{dist} folder.\\
It correctly bundles React in production mode and optimizes the build
for the best performance.

The build is minified and the filenames include the hashes.\\
Your app is ready to be deployed!

\hypertarget{pnpm-run-regteststart}{%
\subsubsection{\texorpdfstring{\texttt{pnpm\ run\ regtest:start}}{pnpm run regtest:start}}\label{pnpm-run-regteststart}}

Starts the regtest environment and sets up the arkd instance.\\
Requires Docker and Node.js v20.19+ or v22.12+. The stack is driven by
the in-house \texttt{arkade-regtest} Node CLI
(\texttt{regtest/regtest.mjs}) --- no Nigiri required.

Use \texttt{pnpm\ run\ regtest:stop} to stop it and
\texttt{pnpm\ run\ regtest:clean} to tear it down.

\hypertarget{funding-your-local-wallet}{%
\subsubsection{Funding your local
wallet}\label{funding-your-local-wallet}}

To interact with Ark features, you need Regtest coins. 1. Copy your
address from the wallet's \textbf{Receive} screen (ensure it starts with
bcrt1 for Regtest). 2. Run the faucet command (the \texttt{-\/-confirm}
flag mines a block so the deposit confirms):

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{node}\NormalTok{ regtest/regtest.mjs faucet }\OperatorTok{\textless{}}\NormalTok{bcrt{-}address}\OperatorTok{\textgreater{}} \OperatorTok{\textless{}}\NormalTok{btc}\OperatorTok{\textgreater{}}\NormalTok{ {-}{-}confirm}
\end{Highlighting}
\end{Shaded}

\hypertarget{address-already-in-use-port-5000-on-macos}{%
\subsubsection{\texorpdfstring{\texttt{address\ already\ in\ use} (Port
5000) on
macOS}{address already in use (Port 5000) on macOS}}\label{address-already-in-use-port-5000-on-macos}}

macOS AirPlay Receiver uses port 5000 by default, which conflicts with
the regtest stack. - \textbf{Fix:} Go to
\texttt{System\ Settings\ \textgreater{}\ General\ \textgreater{}\ AirDrop\ \&\ Handoff}
and disable \textbf{AirPlay Receiver}.
