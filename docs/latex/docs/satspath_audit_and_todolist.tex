  (Dilithium)}. Esto asegura compatibilidad actual mientras protege las
  identidades contra futuros ataques de computación cuántica (Shor's
  algorithm).
\item[$\square$]
  \textbf{Intercambio de Claves P2P:} Transicionar el P2P ECDH (Fase 5)
  a un KEM híbrido que combine curvas elípticas (X25519) con
  \textbf{ML-KEM (Kyber)} para establecer los secretos compartidos.
\item[$\square$]
  \textbf{Migración de Perfiles:} Definir un field en el JSON del
  profile para anunciar soporte PQC y transicionar perfiles clásicos a
  PQC de forma fluida.
\end{itemize}
