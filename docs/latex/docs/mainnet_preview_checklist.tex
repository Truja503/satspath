\section{SatsPath Mainnet Preview
Checklist}\label{satspath-mainnet-preview-checklist}}

SatsPath Preview Mode is a public payment pointer resolver and QR
preview.

It is safe to test with real mainnet public identifiers, public keys,
Lightning Addresses, LNURL metadata, BOLT11 invoices, Ark public
pointers, and Bitcoin addresses because this mode only touches public
data.

Required CLI language:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{SatsPath Preview Mode}
\NormalTok{No funds moved.}
\NormalTok{No signing performed.}
\NormalTok{No private keys touched.}
\NormalTok{Public payment pointer only.}
\end{Highlighting}
\end{Shaded}

Mainnet preview mode:

\begin{itemize}
\tightlist
\item
  Resolves an identifier to a signed public payment profile or local
  peer record.
\item
  Verifies the signed profile before routing.
\item
  Selects the best public route.
\item
  Returns a public payment pointer.
\item
  Builds a QR payload for Lightning, on-chain, or Ark public pointers.
\item
  Uses mainnet address rules when \texttt{-\/-mainnet-preview} is
  passed.
\item
  Rejects QR payloads that appear to contain private material.
\end{itemize}

Mainnet preview mode does not:

\begin{itemize}
\tightlist
\item
  Sign transactions.
\item
  Broadcast transactions.
\item
  Pay invoices.
\item
  Execute swaps.
\item
  Generate seeds.
\item
  Store seeds.
\item
  Touch wallet private keys.
\item
  Touch wallet signing keys.
\item
  Read LND macaroons or node certs.
\item
  Use API secrets.
\item
  Auto-create wallets for unknown users.
\end{itemize}

Unknown user flow remains:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{unknown identifier {-}\textgreater{} invite required {-}\textgreater{} receiver generates keys locally {-}\textgreater{} receiver publishes signed profile {-}\textgreater{} sender re{-}resolves}
\end{Highlighting}
\end{Shaded}

Actual mainnet payment execution must be implemented as a separate
future feature with stronger confirmation gates. Do not call a preview
``payment sent'' or ``payment complete''.
