\hypertarget{ark-swap-safety}{%
\section{Ark Swap Safety}\label{ark-swap-safety}}

Ark swap support is intentionally conservative.

\hypertarget{safety-rules}{%
\subsection{Safety Rules}\label{safety-rules}}

\begin{itemize}
\tightlist
\item
  Mainnet execution is unavailable.
\item
  Preview mode never moves funds.
\item
  SatsPath never stores seed phrases, private keys, macaroons, certs,
  API keys, or passwords in plaintext.
\item
  Swap execution must use encrypted \texttt{SwapStore}.
\item
  Plaintext swap storage is only available through an explicit test/dev
  API.
\item
  Claim/refund builders are required before executing a route that can
  strand funds.
\end{itemize}

\hypertarget{execution-gates}{%
\subsection{Execution Gates}\label{execution-gates}}

Commands that can move testnet funds require:

\begin{itemize}
\tightlist
\item
  \texttt{-\/-testnet},
\item
  \texttt{-\/-execute-testnet},
\item
  \texttt{-\/-confirm\ "execute\ testnet\ ark\ intent"},
\item
  valid signed profile,
\item
  fresh profile,
\item
  valid Ark server URL,
\item
  compressed secp256k1 receiver pubkey,
\item
  verified Ark ownership proof,
\item
  supported Ark bridge method,
\item
  available claim/refund builder for swap routes.
\end{itemize}

If any gate fails, execution is blocked and the command remains
preview-only.

\hypertarget{not-implemented}{%
\subsection{Not Implemented}\label{not-implemented}}

\begin{itemize}
\tightlist
\item
  Mainnet Ark execution.
\item
  Ark funding for Boltz submarine swaps.
\item
  Lightning-to-Ark delivery if Boltz can only deliver to a BTC address.
\item
  Ark onboard address creation and VTXO claiming.
\item
  Ark offboard execution to arbitrary BTC destinations.
\item
  Reverse/chain claim transaction builders.
\item
  Submarine refund transaction builder.
\end{itemize}
