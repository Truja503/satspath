\section{SatsPath × Arkade Wallet --- MVP Technical Integration
Plan}\label{satspath-arkade-wallet-mvp-technical-integration-plan}}

\textbf{Objective}: Enable Arkade wallet users to send/receive Bitcoin
via human-readable aliases (e.g., \texttt{Truja@sexo.ya}) with automatic
rail selection (Lightning → On-chain → Ark), client-side VTXO
verification, and encrypted identity management.

\textbf{Timeline}: 4-6 weeks \textbar{} \textbf{Approach}: WASM bindings
from Rust core to TypeScript wallet

to TypeScript. Arkade wallet calls:

sidecar process.
