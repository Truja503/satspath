\section{SatsPath × Arkade PWA --- Technical Integration Plan
(MVP)}\label{satspath-arkade-pwa-technical-integration-plan-mvp}}

\textbf{Goal}: Arkade PWA sends \texttt{alice@domain.com} +
\texttt{amount\_sats} → receives \texttt{QuoteResponse} with payment
payload + QR → executes payment via LDK (Lightning) / Arkade SDK (Ark) /
BDK (on-chain).

\textbf{Architecture}: PWA (TypeScript) handles resolution →
\texttt{satspath-wasm} verifies profile signature → Router (TypeScript
port) selects rail → Arkade SDK validates VTXO on receive.

\subsection{2. MVP Scope (4--6 weeks)}\label{mvp-scope-46-weeks}}

\hypertarget{in-scope}{%
\subsubsection{In Scope}\label{in-scope}}

\begin{itemize}
\tightlist
\item
  PWA resolves \texttt{alias@domain} via \textbf{TypeScript resolvers}
  (BIP-353 DoH, HTTPS well-known, Nostr NIP-05)
\item
  \texttt{satspath-wasm} verifies \texttt{SignedPaymentProfile}
  signature (secp256k1 Schnorr)
\item
  \textbf{Router ported to TypeScript} (\textasciitilde300 LOC): fee
  fetch → scoring → rail selection → payment payload
\item
  \texttt{QuoteResponse} returned to UI (snake\_case JSON, matches Rust
  exactly)
\item
  Ark receive: Arkade SDK validates VTXO DAG + sovereign exit ready
\item
  Lightning send: PWA calls LDK/Breez SDK with BOLT11 invoice
\item
  On-chain send: PWA calls BDK/rust-bitcoin via WASM or builds BIP-21
  URI
\end{itemize}

\hypertarget{out-of-scope-v2}{%
\subsubsection{Out of Scope (v2)}\label{out-of-scope-v2}}

\begin{itemize}
\tightlist
\item
  Full WASM port of resolver chain + router
\item
  UniFFI bindings for native mobile
\item
  BOLT12, Silent Payments, Split Payments
\item
  Key rotation / profile revocation
\item
  Email/platform verification (invite flow only)
\end{itemize}

\textbf{Resolvers to implement} (in order, first success wins): 1.
\textbf{LocalRegistryResolver} --- reads
\texttt{localStorage{[}"satspath:registry"{]}} (JSON array of
\texttt{SignedPaymentProfile}) 2. \textbf{Bip353Resolver} ---
DNS-over-HTTPS (Google/Cloudflare) for
\texttt{\_bitcoin.payment.\textless{}domain\textgreater{}} TXT → parse
BIP-321 URI 3. \textbf{HttpWellKnownResolver} ---
\texttt{GET\ https://\textless{}domain\textgreater{}/.well-known/satspath/\textless{}alias\textgreater{}.json}
→ \texttt{SignedPaymentProfile} 4. \textbf{NostrNip05Resolver} --- -
\texttt{GET\ https://\textless{}domain\textgreater{}/.well-known/nostr.json?name=\textless{}user\textgreater{}}
→
\texttt{\{\ names:\ \{\ \textless{}user\textgreater{}:\ \textless{}pubkey\textgreater{}\ \},\ relays:\ \{\ \textless{}pubkey\textgreater{}:\ {[}relay...{]}\ \}\ \}}
- Query relays (NIP-01 REQ) for kind 30078 with
\texttt{d\ =\ "satspath-profile:\textless{}alias\textgreater{}"} -
Verify event author pubkey matches NIP-05 pubkey 5. \textbf{P2PResolver}
(optional) --- call local \texttt{satspathd} via HTTP if running (tauri
sidecar)

\textbf{All resolvers}: return \texttt{SignedPaymentProfile} or throw
\texttt{AliasNotFound}.
