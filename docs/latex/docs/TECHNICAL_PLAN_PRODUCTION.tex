\section{SatsPath × Arkade --- Technical Integration Plan (Production /
v2)}\label{satspath-arkade-technical-integration-plan-production-v2}}

\textbf{Goal}: Fully native, self-sovereign SatsPath stack in Arkade
wallet (mobile + desktop) with zero trusted backend. UniFFI bindings for
Kotlin (Android), Swift (iOS), TypeScript (React Native / Tauri / PWA).

\textbf{Architecture}:

\begin{verbatim}
Arkade Wallet (Kotlin/Swift/TS)
    ↓ UniFFI
satspath-core + satspath-router (Rust cdylib)
    ├── Resolver Chain (local → BIP353 → HTTPS → Nostr → P2P)
    ├── Profile Crypto (secp256k1 sign/verify)
    ├── Router (fee-aware rail selection)
    └── QR/Payment Payload Builder
    ↓ Execution Adapters (platform-specific)
LDK (Lightning) / Arkade SDK (Ark) / BDK (On-chain)
\end{verbatim}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}
