\hypertarget{overview-protocol-philosophy}{%
\subsection{1. Overview \& Protocol
Philosophy}\label{overview-protocol-philosophy}}

The SatsPath v2 S2S Wire Protocol defines the HTTP and cryptographic
interface that clients, resolvers, and peer servers use to discover
authority, resolve identifiers, verify cryptographic proofs, and
synchronize transparency logs.

\hypertarget{core-principles}{%
\subsubsection{Core Principles}\label{core-principles}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Self-Contained Proof Envelopes}: A resolution response carries
  all cryptographic proofs necessary for a pure verifier to establish
  integrity, origin, and freshness without querying secondary endpoints.
\item
  \textbf{Deterministic Canonicalization}: All cryptographic commitments
  use strict domain separation (\texttt{SatsPath*V1} /
  \texttt{SatsPath*V2}) and canonical JSON (RFC 8785) formatting.
\item
  \textbf{Fail-Closed Verification}: Any missing mandatory field,
  unknown schema extension, malformed proof, or broken consistency chain
  terminates verification immediately.
\end{enumerate}

\hypertarget{http-endpoints-api-surface}{%
\subsection{4. HTTP Endpoints \& API
Surface}\label{http-endpoints-api-surface}}

All endpoints use
\texttt{Content-Type:\ application/vnd.satspath.v2+json;\ charset=utf-8}.

\hypertarget{authority-discovery}{%
\subsubsection{4.1. Authority Discovery}\label{authority-discovery}}

\begin{itemize}
\tightlist
\item
  \textbf{Endpoint}: \texttt{GET\ /.well-known/satspath-authority}
\item
  \textbf{Query Parameters}: None
\item
  \textbf{Response}: \texttt{200\ OK} with \texttt{NamespaceDescriptor}
\item
  \textbf{Caching}:
  \texttt{Cache-Control:\ public,\ max-age=3600,\ stale-while-revalidate=86400}
\end{itemize}

\hypertarget{proof-carrying-identifier-resolution}{%
\subsubsection{4.2. Proof-Carrying Identifier
Resolution}\label{proof-carrying-identifier-resolution}}

\begin{itemize}
\tightlist
\item
  \textbf{Endpoint}: \texttt{GET\ /v2/resolve}
\item
  \textbf{Query Parameters}:

  \begin{itemize}
  \tightlist
  \item
    \texttt{identifier} (required): Canonical format
    \texttt{user@domain.com} (lowercase, UTF-8).
  \item
    \texttt{pinned\_tree\_size} (optional): Client's last observed tree
    size to request inline consistency proof.
  \item
    \texttt{include\_history} (optional): \texttt{true} / \texttt{false}
    (defaults to \texttt{true}).
  \end{itemize}
\item
  \textbf{Alternative}: \texttt{POST\ /v2/resolve} with JSON body
  \texttt{\{"identifier":\ "...",\ "pinned\_tree\_size":\ ...\}} to
  avoid URL proxy logging of private sub-identifiers.
\item
  \textbf{Response}: \texttt{200\ OK} with \texttt{ResolutionEnvelope}.
\item
  \textbf{Errors}:

  \begin{itemize}
  \tightlist
  \item
    \texttt{404\ Not\ Found}: Identifier does not exist (returns
    cryptographically signed non-inclusion proof).
  \item
    \texttt{400\ Bad\ Request}: Malformed identifier syntax.
  \item
    \texttt{503\ Service\ Unavailable}: Log synchronization in progress.
  \end{itemize}
\end{itemize}

\hypertarget{checkpoint-retrieval}{%
\subsubsection{4.3. Checkpoint Retrieval}\label{checkpoint-retrieval}}

\begin{itemize}
\tightlist
\item
  \textbf{Endpoint}: \texttt{GET\ /v2/checkpoint}
\item
  \textbf{Response}: \texttt{200\ OK} with latest
  \texttt{TransparencyCheckpoint} and attached
  \texttt{witness\_cosignatures}.
\item
  \textbf{Caching}: \texttt{Cache-Control:\ public,\ max-age=15}
\end{itemize}

\hypertarget{consistency-proof-retrieval}{%
\subsubsection{4.4. Consistency Proof
Retrieval}\label{consistency-proof-retrieval}}

\begin{itemize}
\tightlist
\item
  \textbf{Endpoint}: \texttt{GET\ /v2/proof/consistency}
\item
  \textbf{Query Parameters}:

  \begin{itemize}
  \tightlist
  \item
    \texttt{old} (required): Previous tree size \(N_1\).
  \item
    \texttt{new} (required): Target tree size \(N_2\) (\(N_2 \ge N_1\)).
  \end{itemize}
\item
  \textbf{Response}: \texttt{200\ OK} with
  \texttt{MerkleConsistencyProof} (RFC 6962 format).
\end{itemize}

\hypertarget{monitor-entry-stream}{%
\subsubsection{4.5. Monitor Entry Stream}\label{monitor-entry-stream}}

\begin{itemize}
\tightlist
\item
  \textbf{Endpoint}: \texttt{GET\ /v2/entries}
\item
  \textbf{Query Parameters}:

  \begin{itemize}
  \tightlist
  \item
    \texttt{from} (required): Start leaf index (inclusive, 0-indexed).
  \item
    \texttt{to} (required): End leaf index (inclusive, max delta: 1000).
  \end{itemize}
\item
  \textbf{Response}: \texttt{200\ OK} with JSON array of
  \texttt{NameEvent} leaves.
\end{itemize}

\hypertarget{pure-verification-algorithm-normative}{%
\subsection{5. Pure Verification Algorithm
(Normative)}\label{pure-verification-algorithm-normative}}

A compliant SatsPath v2 verifier executes the following ordered
sequence:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{[1. Namespace Verification]}
\NormalTok{    ├── Validate DNSSEC on \_satspath.domain.com OR check WebPKI / Pin.}
\NormalTok{    ├── Verify namespace\_descriptor.signature against authority\_pubkey.}
\NormalTok{    └── Check namespace\_descriptor expiration: expires\_at \textgreater{} now.}

\NormalTok{[2. Profile \& Event Chain Verification]}
\NormalTok{    ├── Verify signed\_profile signature with profile.identity\_pubkey.}
\NormalTok{    ├── Compute profile\_hash = H(SatsPathSignedPaymentProfileV1 || canonical\_profile || signature).}
\NormalTok{    ├── Verify name\_events sequence (0..N) monotonic hash chain.}
\NormalTok{    ├── Assert name\_events[N].profile\_hash == profile\_hash.}
\NormalTok{    └── Assert name\_events[N].identity\_pubkey == signed\_profile.identity\_pubkey.}

\NormalTok{[3. Merkle Leaf \& Checkpoint Inclusion]}
\NormalTok{    ├── Compute leaf\_hash = H(0x00 || H(SatsPathSignedNameEventV1 || canonical(name\_events[N]))).}
\NormalTok{    ├── Verify inclusion\_proof connects leaf\_hash to checkpoint.log\_root at log\_size.}
\NormalTok{    └── Verify checkpoint.operator\_signature using checkpoint.operator\_pubkey.}

\NormalTok{[4. Checkpoint Extension \& Consistency]}
\NormalTok{    ├── If client has pinned checkpoint (size S\_old, root R\_old):}
\NormalTok{    │     ├── If checkpoint.log\_size \textless{} S\_old: FAIL(ERR\_CHECKPOINT\_ROLLBACK).}
\NormalTok{    │     ├── If checkpoint.log\_size == S\_old: Assert checkpoint.log\_root == R\_old.}
\NormalTok{    │     └── If checkpoint.log\_size \textgreater{} S\_old: Verify consistency\_proof(S\_old, S\_new, R\_old, R\_new).}
\NormalTok{    └── If operator\_pubkey changed: Verify operator\_rotation dual{-}signatures.}

\NormalTok{[5. Witness Quorum Verification]}
\NormalTok{    ├── Filter witness\_cosignatures matching namespace\_descriptor.witness\_pubkeys.}
\NormalTok{    ├── Verify each witness signature over checkpoint\_hash and tree\_size.}
\NormalTok{    └── Assert valid\_witness\_count \textgreater{}= namespace\_descriptor.witness\_quorum.}
\end{Highlighting}
\end{Shaded}
