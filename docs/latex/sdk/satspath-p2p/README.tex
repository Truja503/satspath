\hypertarget{satspathp2p}{%
\section{@satspath/p2p}\label{satspathp2p}}

Resolve \& serve \textbf{SatsPath signed payment profiles peer-to-peer}
over the \href{https://holepunch.to}{Holepunch} stack (Hyperswarm /
HyperDHT), with NAT hole-punching --- no central server and no local
pre-registration of the receiver.

A wallet that embeds this SDK automatically gets a \textbf{random node
address} and can publish or resolve \texttt{user@domain} payment
profiles directly between devices.

\begin{quote}
Transport + verification only. This SDK moves \textbf{only public,
signed payment profiles}. It never moves funds, signs Bitcoin
transactions, or broadcasts. Trust comes from the secp256k1
\textbf{signature}, not from the transport.
\end{quote}

\hypertarget{how-it-works}{%
\subsection{How it works}\label{how-it-works}}

\begin{verbatim}
receiver device                         sender device
───────────────                         ─────────────
satspath export rodrigo@x.dev           node = new SatsPathP2PNode()
   → rodrigo.json                       node.address  ← auto-generated, random
node.publish(rodrigo.json)              await node.resolve("rodrigo@x.dev")
   topic = sha256("…:rodrigo@x.dev")        │ join same topic, DHT lookup
   announce on HyperDHT  ───────────────────┘ hole-punch + connect
   serve profile to peers  ───────────────▶  receive → VERIFY SIGNATURE → return
\end{verbatim}

\begin{itemize}
\tightlist
\item
  \textbf{Address.} Each node has an auto-generated random Ed25519
  keypair (Hyperswarm's Noise identity). \texttt{node.address} is its
  hex public key --- \emph{not} a Bitcoin key and controls no funds.
\item
  \textbf{Discovery.} The DHT topic is
  \texttt{sha256("satspath:p2p:v1:"\ +\ canonicalAlias)}, so publisher
  and resolver find each other from the alias alone.
\item
  \textbf{Trust.} A resolved profile is accepted only if
  \texttt{verifySignedProfile} passes (secp256k1 ECDSA over
  \texttt{sha256(serde\_json(profile))}, matching the Rust core) and its
  alias matches the request. A tampered profile is rejected.
\end{itemize}

On the \textbf{sender's} machine (different computer / network):

\begin{Shaded}
\begin{Highlighting}[]
\BuiltInTok{cd}\NormalTok{ sdk/satspath{-}p2p }\KeywordTok{\&\&} \ExtensionTok{npm}\NormalTok{ install}

\hypertarget{safety}{%
\subsection{Safety}\label{safety}}

\begin{itemize}
\tightlist
\item
  No funds moved, nothing signed or broadcast --- public signed profiles
  only.
\item
  The node keypair is a P2P identity, \textbf{not} a wallet
  seed/spending key.
\item
  A profile is trusted only after its signature verifies; the
  DHT/transport is never trusted on its own.
\end{itemize}
