\hypertarget{overview}{%
\subsection{Overview}\label{overview}}

This suite ensures the cryptographic integrity of the scripts, Merkle
trees, and timelocks that define Ark's exit policies and atomic swap
conditions.

\hypertarget{test-goals}{%
\subsubsection{🎯 Test Goals}\label{test-goals}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{BIP 341/342 Compliance}: Verifying Tapleaf script hashing and
  Merkle proof validation.
\item
  \textbf{Ark Exit Policies}: Checking for the presence of mandatory
  \texttt{CHECKSEQUENCEVERIFY} in Ark leaves.
\item
  \textbf{HTLC Atomic Swaps}: Validating hash lock and locktime
  satisfaction for \textbf{Boltz Submarine Swaps}.
\end{enumerate}

\hypertarget{environment}{%
\subsubsection{🌐 Environment}\label{environment}}

\begin{itemize}

  \textbf{Providers}: \texttt{MockIndexerProvider} and
  \texttt{MockOnchainProvider}.
\item
  \textbf{Data Source}: Custom scripts (\texttt{P2TR}) with embedded
  \texttt{HASH160} and \texttt{SHA256} conditions.
\item
  \textbf{Execution}: Node.js/Vitest environment.
\end{itemize}
