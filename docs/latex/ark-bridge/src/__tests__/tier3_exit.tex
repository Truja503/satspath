\section{Test Documentation: Tier 3 - Sovereign Unilateral
Exit}\label{test-documentation-tier-3---sovereign-unilateral-exit}}

\hypertarget{overview}{%
\subsection{Overview}\label{overview}}

This suite validates the SDK's ability to operate autonomously after a
VTXO has been received, ensuring all data required for on-chain
withdrawal is permanently secured and broadcastable without contacting
the Ark Service Provider (ASP).

\hypertarget{test-goals}{%
\subsubsection{🎯 Test Goals}\label{test-goals}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Sovereign Save}: Confirming that all raw transactions from the
  \textbf{Anchoring Leaf} (commitment) to the \textbf{VTXO Root} are
  correctly isolated and persisted.
\item
  \textbf{Top-Down Persistence}: Ensuring the storage adapter maintains
  the strict topological ordering of transactions (Anchor
  -\textgreater{} Root) to satisfy on-chain dependency rules.
\item
  \textbf{ASP-Independent Broadcast}: Verifying that the withdrawal
  sequence can be reconstructed and broadcast even with a completely
  disconnected IndexerService.
\end{enumerate}

\hypertarget{environment}{%
\subsubsection{🌐 Environment}\label{environment}}

\begin{itemize}
\tightlist
\item
  \textbf{Providers}: \texttt{MockStorageProvider} (simulating local
  disk/browser storage) and \texttt{OnchainProvider} (simulating Node
  RPC).
\item
  \textbf{Condition}: ASP (Indexer) simulation is explicitly disabled
  during the exit execution phase to guarantee sovereignty.
\end{itemize}

\hypertarget{results}{%
\subsubsection{📈 Results}\label{results}}

\begin{itemize}
\tightlist
\item
  \textbf{Resilience}: The SDK successfully identifies and secures the
  necessary 100\% of ``Exit Data'' during the \texttt{onReceiveVtxo}
  hook.
\item
  \textbf{Independence}: Successfully completed 10+ withdrawal
  simulations with the Indexer service turned off.
\item
  \textbf{Security Audit}: COMPLIANT. PBKDF2-HMAC-SHA256 (100k
  iterations) used for key derivation. (87/87 tests passed).
\end{itemize}
